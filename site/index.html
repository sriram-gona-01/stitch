Why it might work

Switching models throws away what you already paid for.

The prompt cache belongs to one model. Change the main session's model and the next turn rebuilds it. Hand a task to a subagent and the main cache isn't touched. The subagent pays only for a short brief.

Switch the main model

All the context gets written again at the higher cache-write price.

Delegate to a subagent

The cost is the brief, the subagent's own turns, and the summary. Bars are illustrative, not to scale.

How it's built

Five small layers, each easy to swap.

  1. 1MeasureReads Claude Code transcripts, removes duplicate usage, and tags every request by feature, phase, arm, and agent.
  2. 2Shrinklw run saves long command output to a file and prints a short summary.
  3. 3OrganizeA lean CLAUDE.md, state files, brief and summary templates, a five-agent roster, and a verification gate.
  4. 4DecideA break-even advisor compares staying, delegating, restarting, and compacting in plain numbers. It recommends and never switches.
  5. 5ProveArms from plain Claude Code to the full harness, a written experiment protocol, and a report with quality guardrails beside the cost.

See where the tokens went.

Arm is now route: Adds delegation to cheaper models.

fragments: routing
Start a fresh Claude Code session: agents and hooks load at session start.

$ uv run lw arm baseline
Arm is now baseline: Plain Claude Code. Logging only; no agents, behavior hooks, or routing rules.
agents: (none)
fragments: (none)

Quickstart

Try it on your own feature.

git clone https://github.com/sriram-gona-01/light-work.git
cd light-work
uv sync
uv run lw arm route
uv run lw feature start F1
# Start a fresh Claude Code session and build the feature
uv run lw usage --feature F1 --by agent
